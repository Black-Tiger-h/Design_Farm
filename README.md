# Design_Farm

**예술대학생의 작품과 다음 기회를 연결하는 온라인 미술관.**

중간·기말 평가를 위해 만든 작품이 새로운 공간과 사람을 만날 수 있도록, 작품 감상부터 경매 참여와 작가 협업 제안까지 연결합니다. 구매자는 작가가 직접 소개한 작품의 크기, 어울리는 공간, 배치 방법을 참고해 취향에 맞는 작품을 찾습니다.

현재는 **구매자와 학생 작가 양쪽의 화면 및 사용 흐름을 확인하는 HTML 프로토타입**입니다. 여백과 작품 중심의 미술관 분위기로 구성했습니다.

## 실행하기

별도 패키지 설치나 빌드 없이 `index.html`을 브라우저로 열 수 있습니다.

로컬 서버를 사용하려면 Python 3가 설치된 환경에서 다음 명령을 실행하세요.

```sh
git clone https://github.com/Black-Tiger-h/Design_Farm.git
cd Design_Farm
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:4173>에 접속합니다. 수정한 화면이 보이지 않으면 페이지를 새로고침하세요. 서버 종료는 `Ctrl+C`입니다.

## 주요 기능

| 영역 | 체험할 수 있는 기능 |
| --- | --- |
| 작품 전시 | 실물·디지털 작품 감상, 작품·작가 검색, 종류별 필터, 정렬, 관심 작품 |
| 공간 제안 | 작품 크기·재료 확인, 어울리는 공간별 필터, 작가가 작성한 배치 안내 |
| 경매 | 시작가 및 입찰 이력 확인, 입찰, 마감 결과 체험 |
| 작품 등록 | 이미지와 작품 정보, 시작가, 추천 공간 및 배치 방법 입력 |
| 작가와 커리어 | 시안용 낙찰 건수에 따른 순위, 작가 소개 및 작품 목록 |
| 협업 제안 | 스카우트·외주 요청 양식 작성, 내 활동에서 요청 확인 |
| 내 활동 | 참여한 경매, 등록한 작품, 보낸 요청과 내 작가에게 온 요청 확인 |

### 둘러보기 순서

1. **작품 둘러보기**에서 공간을 선택하고 작품 상세의 크기와 공간 제안을 확인합니다.
2. 작품에 입찰한 뒤 **내 활동 → 마감 결과 체험**으로 낙찰 흐름을 확인합니다.
3. **작품 등록**에서 학생 작가의 등록 과정을 체험합니다.
4. **작가와 커리어 → 작가와 작품 보기**에서 스카우트 또는 외주 요청을 작성합니다.

## 경매와 순위 기준

- 학생 작가가 시작가를 정하며, 첫 입찰은 시작가부터 가능합니다.
- 입찰 금액은 1,000원 단위이고, 다음 입찰은 현재 최고가보다 최소 1,000원 높아야 합니다.
- 한 명만 시작가에 입찰해도 해당 금액에 낙찰됩니다. 입찰이 없으면 유찰됩니다.
- 예상 가격대는 1만~10만 원이며, 입찰 상한을 뜻하지 않습니다.
- 작가 순위는 시안용 낙찰 건수를 기준으로 합니다. 진행 중인 입찰과 유찰은 포함하지 않으며, 동률은 같은 순위를 부여합니다.

## 프로토타입 범위

작품·작가 정보와 초기 거래 실적은 예시입니다. 입찰·등록·관심 작품·요청은 현재 페이지의 메모리에서만 관리되어 **새로고침하면 초기화**됩니다.

로그인, 학생 인증, 서버·데이터베이스, 실제 결제·정산·배송은 구현하지 않았습니다. 스카우트·외주 요청은 실제 상대에게 전달되지 않습니다. 순위는 검증된 경력이나 실제 거래 실적을 의미하지 않습니다.

디지털 작품의 판매 횟수, 독점 여부와 이용 조건은 추후 결정할 사항입니다.

## 기술 구성

HTML, CSS, JavaScript와 내장 SVG 예시 작품으로 구성되어 있습니다. 프런트엔드 프레임워크나 외부 패키지를 사용하지 않습니다.

```text
index.html       화면, 스타일, 예시 작품, 경매·커리어 로직
check.cjs        경매 및 작가 순위 로직 검사
docs/            제품 기획서
```

## 검사 실행

Node.js 18 이상에서 별도 의존성 설치 없이 실행합니다.

```sh
node check.cjs
```

시작가, 최소 입찰 증가액, 잘못된 금액, 단독 입찰 낙찰, 유찰, 마감 이후 입찰 차단 및 작가 순위 집계를 검사합니다. 화면 전체를 자동 검사하는 테스트는 아닙니다.
